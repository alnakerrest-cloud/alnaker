# 04 — دليل استخدام لوحة التحكم الإدارية (Admin Dashboard User Manual)

**المشروع:** منيو قرية الناقر (Naqer Menu)  
**المسار الأساسي:** `/admin`  
**تاريخ التوثيق:** نوفمبر 2026  
**الفئة المستهدفة:** مالك المطعم (OWNER) ومسؤولو إدارة المحتوى (EDITOR)  

---

## 1. الدخول إلى النظام (Login Procedure)

- **رابط تسجيل الدخول:** `https://<domain>/admin/login`
- **الحقول المطلوبة:**
  1. **البريد الإلكتروني:** البريد المعتمد للمدير (مثل `owner@naqer.com`).
  2. **كلمة المرور:** كلمة المرور السرية المنشأة للمدير.
- **الحماية المطبقة:**
  - محدد معدل الطلبات (Rate Limiter): يُقفل نموذج الدخول تلقائياً عند تكرار المحاولات الخاطئة لمنع هجمات التخمين.
  - الجلسة آمنة تماماً وتدوم لمدة 7 أيام، وتُلغى فوراً عند النقر على "تسجيل الخروج".

## 2. جدول الشاشات والمسارات والصلاحيات (Pages & RBAC Matrix)

| اسم الشاشة | المسار (Route) | الصلاحية المطلوبة | الغرض والمسؤولية |
|:---|:---|:---:|:---|
| **الرئيسية (Dashboard)** | `/admin/dashboard` | OWNER / EDITOR | عرض ملخص الأرقام، وروابط العمل السريعة، وأحدث التعديلات. |
| **المنتجات (Products)** | `/admin/products` | OWNER / EDITOR | استعراض الأطباق، والبحث، وتعديل الأسعار وتوافر الوجبات. |
| **إضافة منتج** | `/admin/products/new` | OWNER / EDITOR | إدخال طبق جديد مع أسعاره وخياراته ومكوناته. |
| **تعديل المنتج والوسائط** | `/admin/products/[id]` | OWNER / EDITOR | تعديل تفاصيل الطبق، وإدارة الأسعار، ورفع واستبدال وحذف الصور. |
| **الأقسام (Categories)** | `/admin/categories` | OWNER / EDITOR | ترتيب الأقسام وإدارتها وإخفائها أو إظهارها في المنيو. |
| **إضافة قسم** | `/admin/categories/new` | OWNER / EDITOR | إنشاء قسم جديد وتحديد نمط عرضه (صواني أو قائمة). |
| **تعديل القسم** | `/admin/categories/[id]` | OWNER / EDITOR | تعديل بيانات القسم ورفع صورة الغلاف السحابية للقسم. |
| **الفروع (Branches)** | `/admin/branches` | OWNER / EDITOR | إدارة الفروع وأرقام هواتف الواتساب ومواعيد العمل. |
| **تعديل الفرع** | `/admin/branches/[id]` | OWNER / EDITOR | تحديث بيانات الفرع بدقة ورابط الخريطة وتفعيل الطلبات. |
| **الإضافات (Addons)** | `/admin/addons` | OWNER / EDITOR | إدارة مجموعات الخيارات (مثل نوع الأرز، إضافات الجبن). |
| **العروض (Offers)** | `/admin/offers` | OWNER / EDITOR | إنشاء وإدارة التخفيضات والعروض الخاصة. |
| **مكتبة الوسائط** | `/admin/images` | OWNER / EDITOR | استعراض جميع الصور والتأكد من اتصال Cloudinary السحابي. |
| **سجل التدقيق (Audit)** | `/admin/audit` | **OWNER حصراً** | مراقبة سجل التعديلات التفصيلي لكل مديري ومحرري النظام. |
| **إعدادات المطعم** | `/admin/settings` | **OWNER حصراً** | تحديث شعار المطعم، واسم الهوية، وملاحظات الضريبة، وإدارة كلمة المرور. |
| **تعيين كلمة المرور** | `/admin/change-password` | **OWNER حصراً** | شاشة الأمان الإلزامية لتغيير كلمة المرور عند أول دخول أو إجبار النظام. |

> [!IMPORTANT]
> **قاعدة فصل الصلاحيات:**  
> يمكن لـ `EDITOR` إنشاء وتعديل كافة المنتجات والأسعار والصور، ولكن **أزرار الحذف النهائي** محجوبة عنه تماماً ولا تظهر إلا للمالك `OWNER`.

## 3. دليل المهام اليومية لمالك المطعم (Step-by-Step Operations)

### 3.1. كيفية إخفاء طبق نافد (Mark as Sold Out)
عند نفاد طبق معين خلال ساعات العمل ورغبتك في عدم إظهاره للزبائن:
1. اذهب إلى قائمة **المنتجات** (`/admin/products`).
2. ابحث عن اسم الطبق في خانة البحث (مثل: "صينية الوحوش").
3. في عمود "الحالة"، انقر على زر التبديل **"متوفر"** ليتحول إلى **"غير متوفر"**.
4. **النتيجة الفورية:** يختفي الطبق فوراً من شاشات الزبائن خلال 15 ثانية عبر نظام LiveSync دون الحاجة لتدخل فني.

### 3.2. كيفية تعديل سعر طبق
1. من صفحة **المنتجات**، انقر على زر **"تعديل"** أمام الطبق المطلوب.
2. انتقل إلى قسم **"الأسعار والأحجام (Variants)"**.
3. قم بتعديل الرقم في خانة السعر (مثال: تغيير 450 إلى 480).
4. انقر على **"حفظ التعديلات"** أسفل الصفحة.

### 3.3. كيفية رفع أو استبدال صورة لطبق (Cloudinary Media)
1. في صفحة تعديل المنتج (`/admin/products/[id]`)، انتقل إلى مربع **"إدارة الصور"**.
2. انقر على **"اختيار ملف صورة"** (يدعم JPG، PNG، WEBP بحجم أقصاه 5 ميجابايت).
3. انقر على زر **"رفع إلى Cloudinary"**.
4. سيتم رفع الصورة تلقائياً، وضغطها لتناسب سرعات الهواتف، وربطها بالطبق.
5. يمكنك تحديد الصورة كـ **"صورة أساسية"** للطبق بنقرة واحدة، أو حذف الصورة القديمة بأمان (سيقوم النظام بحذفها تلقائياً من سيرفر Cloudinary لمنع تراكم الملفات غير المستخدمة).

### 3.4. كيفية إضافة فرع جديد أو تعديل رقم الواتساب
1. اذهب إلى تبويب **"الفروع"** (`/admin/branches`).
2. انقر على تعديل الفرع (مثل: "فرع جمصة").
3. في خانة **"رقم الواتساب"**، اكتب رقم الهاتف بصيغته الدولية دون مسافات (مثال: `201094965222`).
4. تأكد من تفعيل خيار **"يستقبل طلبات (Orderable)"** وخيار **"نشط (Active)"**.
5. انقر على **"حفظ الفرع"**. سيتم تحويل أي طلب يختاره الزبون لهذا الفرع إلى هذا الرقم مباشرة.

### 3.5. كيفية إنشاء عرض ترويجي (Special Offer)
1. اذهب إلى صفحة **"العروض والخصومات"** (`/admin/offers`).
2. انقر على **"إضافة عرض جديد"**.
3. حدد نوع العرض:
   - **نسبة مئوية:** مثل كتابة `15` لخصم 15%.
   - **مبلغ ثابت:** مثل كتابة `50` لخصم 50 ج.م من الإجمالي.
4. حدد تاريخ البداية والنهاية وشارة العرض (Badge) مثل "عرض نهاية الأسبوع".
5. فعّل خيار **"العرض نشط (Active)"** وانقر على **"حفظ"**.
6. سيظهر شريط العرض فوراً في الصفحة الرئيسية للمنيو، وتُحسب الخصومات في السلة تلقائياً.

### 3.6. كيفية تغيير كلمة مرور حساب المالك (OWNER Password Management)
1. توجه إلى صفحة **"إعدادات المطعم"** (`/admin/settings`).
2. في أسفل الصفحة، ستجد قسماً مخصصاً بعنوان **"إدارة أمان الحساب وكلمة المرور (OWNER)"**.
3. أدخل كلمة المرور الحالية للتأكد من هويتك.
4. أدخل كلمة المرور الجديدة (يجب ألا تقل عن 8 أحرف وتحتوي على أرقام وحروف وتكون مختلفة عن الحالية).
5. أعد إدخال كلمة المرور في خانة التأكيد.
6. انقر على **"تغيير كلمة المرور"**.
7. تظهر رسالة تأكيد النجاح، ويقوم النظام تلقائياً وبأمان بإبطال كافة الجلسات النشطة على الأجهزة الأخرى لحماية حسابك.
