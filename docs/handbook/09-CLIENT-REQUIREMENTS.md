# 09 — متطلبات العميل وقائمة التجهيز التشغيلي (Client Requirements & Operational Checklist)

يوفر هذا المستند دليلاً عملياً وقائمة تحقق (Checklist) واضحة ومحددة لكافة المواد، البيانات، الحسابات، والقرارات التشغيلية التي يجب على صاحب المطعم (أو ممثله الرسمي) تزويد المطور بها لإتمام إطلاق وتشغيل نظام «ناقر منيو» بنجاح.

---

## 1. الهوية التجارية والبيانات الأساسية (Brand Identity)

يجب تزويد المطور بالبيانات التالية لضبط النصوص والعناصر البصرية في الواجهة:

* [ ] **الاسم التجاري الرسمي:**
  * الاسم بالعربية (مثال: ناقر منيو - Naqer Menu).
  * الاسم بالإنجليزية (مثال: Naqer Menu).
* [ ] **الشعار الرسمي (Logo):**
  * شعار مفرغ الخلفية بصيغة PNG أو SVG بجودة عالية (دقة لا تقل عن 512×512 بكسل).
  * أيقونة الموقع (Favicon) مربعة.
* [ ] **الألوان المعتمدة (Branding Colors):**
  * اللون الأساسي (Primary Color - الكود السداسي مثلاً: `#ea580c` أو المعتمد في الهوية).
  * اللون الثانوي وألوان أزرار الدعوة للإجراء (Call to Action).
* [ ] **شعار الترويج (Tagline) ونبذة المطعم:**
  * نص ترحيبي موجز يظهر في أعلى القائمة للزبائن بالعربية والإنجليزية.

---

## 2. بيانات الفروع وأرقام استقبال الطلبات (Branches & Contact)

تعتمد آلية توجيه الطلبات عبر واتساب كلياً على دقة أرقام الهواتف:

* [ ] **قائمة بجميع الفروع العاملة:**
  * اسم كل فرع بالعربية والإنجليزية (مثال: فرع التجمع الخامس - New Cairo Branch).
  * العنوان الجغرافي التفصيلي للفرع.
  * رابط الموقع على خرائط جوجل (Google Maps URL).
* [ ] **أرقام الواتساب المخصصة لاستقبال الطلبات لكل فرع:**
  * يجب تقديم الأرقام بالصيغة الدولية المكتملة بدون أصفار بادئة أو مسافات (مثال في مصر: `201012345678`، وفي السعودية: `966501234567`).
  * التأكد من وجود تطبيق واتساب أو واتساب للأعمال (WhatsApp Business) نشط ومثبت على هاتف مخصص بالفرع لاستقبال الرسائل فوراً.
* [ ] **ساعات العمل وأوقات التوصيل:**
  * مواعيد فتح وغلق كل فرع (لتضمينها في رسائل التوجيه أو تنبيهات الطلب).

---

## 3. محتوى المنيو والأسعار (Menu Content & Structure)

لتجنب أي إرباك أو تأخير، يجب تزويد المطور أو فريق الإدخال بملف إلكتروني مهيكل (Excel أو Google Sheet أو Word) يتضمن:

* [ ] **التصنيفات الرئيسية (Categories):**
  * مثال: مأكولات (Food)، مشروبات (Drinks)، حلويات (Desserts).
* [ ] **الأقسام الفرعية (Sections):**
  * مثال: المشويات، مندي ومظبي، طواجن، مقبلات، عصائر طازجة، قهوة.
* [ ] **تفاصيل كل منتج (Products):**
  * اسم الصنف بالعربية وبالإنجليزية.
  * وصف موجز للمكونات والنكهة بالعربية والإنجليزية.
  * السعر الأساسي بالعملة المحلية.
  * هل المنتج نباتي (Vegetarian)، حار (Spicy)، أو صنف مميز (Featured)؟
* [ ] **الأحجام والخيارات (Variants & Portions):**
  * هل الصنف يتوفر بأحجام مختلفة؟ (مثال: ربع تيس، نصف تيس، تيس كامل؛ أو صغير، وسط، كبير) مع سعر كل حجم بدقة.
* [ ] **الإضافات والصلصات (Addons & Extras):**
  * هل يمكن إضافة صوصات أو مقبلات إضافية مع الصنف وسعر كل إضافة؟

---

## 4. المواد البصرية وتصوير الأطعمة (Photography & Visual Assets)

تلعب الصور دوراً حاسماً في معدل تحويل الزوار إلى طلبات مؤكدة:

* [ ] **صور الأصناف (Product Photos):**
  * صور حقيقية عالية الجودة للأطباق.
  * **النسبة الموصى بها:** نسبة أبعاد مربعة 1:1 (مثلاً: 800×800 بكسل) أو 4:3.
  * **الصيغ المقبولة:** WebP, PNG, JPEG.
  * إضاءة احترافية واضحة وخلفية متناسقة.
* [ ] **لافتات العروض الترويجية (Offer Banners):**
  * صور أفقية بنسبة 16:9 للعروض الخاصة أو الإعلانات التي تظهر أعلى القائمة.

---

## 5. الحسابات السحابية المطلوبة من العميل (Required Accounts)

لكي تكون ملكية النظام مستقلة وقانونية بالكامل تحت إدارة العميل، يُطلب من العميل إما إنشاء هذه الحسابات أو تسليم بريد مخصص لتسجيلها:

| الخدمة | الغرض | المطلوب من العميل |
| :--- | :--- | :--- |
| **مسجل النطاقات (Domain Registrar)** | حجز اسم النطاق الرسمي للمطعم (مثلاً: `naqermenu.com`) | شراء النطاق عبر Namecheap أو Cloudflare ببطاقة العميل وتزويد المطور بصلاحية الـ DNS. |
| **Vercel** | استضافة الواجهة وخوادم التطبيق | إنشاء حساب مجاني ببريد المطعم ودعوة المطور. |
| **Neon** | قاعدة البيانات السحابية PostgreSQL | إنشاء حساب وتوثيقه، أو إنشاء مشروع مستقل بواسطة المطور وتسليم صلاحية المالك. |
| **Cloudinary** | سحابة تخزين وإدارة الصور | إنشاء حساب مجاني وتزويد المطور بمفاتيح API (Cloud Name, API Key, API Secret). |
| **GitHub (اختياري)** | مستودع الشفرة المصدرية (Source Code) | حساب GitHub لنقل ملكية الـ Repository حال الاتفاق على تسليم الكود البرمجي كاملاً. |

---

## 6. السياسات التشغيلية للمطعم (Restaurant Operating Policies)

* [ ] **سياسة الحد الأدنى للطلب (Minimum Order):** هل يوجد حد أدنى لإرسال الطلب عبر واتساب؟
* [ ] **تكلفة التوصيل والمناطق المشمولة:** هل يتم التوصيل لجميع المناطق أم مناطق محددة لكل فرع؟
* [ ] **طرق الدفع:** توضيح للزبون في رسالة الواتساب إن كان الدفع عند الاستلام (كاش) أو عبر محافظ إلكترونية (مثل فودافون كاش / إنستاباي / مدى).
