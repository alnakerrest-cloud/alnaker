# الدليل الإرشادي الشامل والتوثيق المرجعي — ناقر منيو (Naqer Menu Master Handbook)

مرحباً بك في الدليل الإرشادي والتوثيق الهندسي الشامل لنظام **«ناقر منيو» (Naqer Menu)** — منصة المنيو الإلكتروني التفاعلي وطلب الوجبات عبر واتساب للمطاعم والمقاهي.

تم تصميم هذا الدليل ليكون مرجعاً تقنياً وتشغيلياً مستقلاً ومتكاملاً يمكّن أي مطور برمجيات أو صاحب مطعم أو مدير تشغيل من فهم، إدارة، صيانة، وتطوير النظام بكفاءة واستقلالية كاملة.

## 2. ملخص البنية والجاهزية التشغيلية (System Status Snapshot)

* **حالة النظام البرمجية:** جاهز تماماً للإنتاج (Production Ready - Verdict PASS).
* **إصدار Next.js:** `16.4.2` (React `19.1.0` مع دعم المعمارية الحديثة).
* **قاعدة البيانات:** PostgreSQL عبر شبكة Neon السحابية بتقنية Serverless Connection Pooling.
* **إجمالي السجلات الحقيقية:** 151 منتجاً نشطاً، 18 تصنيفاً نشطاً، 151 صورة عالية الدقة، وفرعان مفعلان لاستقبال الطلبات الفورية.
* **محرك المزامنة اللحظية (LiveSync Engine):** مفعل بالكامل لتحديث شاشات الزبائن فور تعديل الأسعار أو الأصناف من قِبل الإدارة دون الحاجة لإعادة تحميل الصفحة.
* **تكلفة التشغيل الأساسية:** **0$ / شهر** على الباقات المجانية السخية للخدمات المعتمدة (+ ~12$ سنوياً للنطاق الرسمي فقط).
