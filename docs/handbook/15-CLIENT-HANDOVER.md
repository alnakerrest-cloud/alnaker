# 15 — وثيقة التسليم النهائي ومحضر استلام العميل (Client Handover & Formal Acceptance)

توثق هذه الوثيقة إجراءات التسليم النهائي لنظام «ناقر منيو» (Naqer Menu)، وتحدد روابط الوصول الرسمية، حالة حسابات المشرفين، حدود الضمان والدعم الفني، ومحضر التسليم والاستلام الرسمي بين المطور وصاحب المطعم.

## 2. حالة حساب المالك وتسليمه الآمن (OWNER Account Handover Status)

* **الوضع الحالي في قاعدة البيانات:**
  * تم تجهيز حساب افتراضي مبدئي برتبة مالك (`OWNER`) باسم: `admin@naqer-menu.local`.
  * كلمة المرور مشفرة بأمان بخوارزمية bcrypt بـ 12 دورة تشفير.
* **إجراء تسليم الحساب الرسمي لصاحب المطعم:**
  * **يمنع منعاً باتاً** إرسال كلمات المرور عبر البريد أو المحادثات غير المشفرة.
  * يتم تفعيل البريد الحقيقي وكلمة المرور الخاصة بالعميل مباشرة عبر سكريبت التخصيص الآمن:
    ```bash
    node scripts/provision-owner.mjs "owner@restaurant-name.com" "StrongPassword123!"
    ```
  * فور تسجيل الدخول الأول، يوصى بقيام العميل بتغيير كلمة المرور من لوحة التحكم وحفظها في برنامج إدارة كلمات مرور آمن (Password Manager).

## 3. قائمة تدقيق التسليم الفني (Handover Verification Checklist)

تم إنجاز والتحقق من كافة البنود التالية من قِبل المطور قبل إتمام التسليم:

- [x] تفعيل تشفير الاتصال الآمن (HTTPS / SSL) على كامل النطاق والمسارات.
- [x] إخفاء وتأمين كافة بيانات الاعتماد والمفاتيح السرية داخل متغيرات البيئة.
- [x] التحقق من تحميل جميع صور الأصناف (151 صورة) بجودة عالية وسرعة فائقة.
- [x] اختبار سلة المشتريات وإرسال طلبات حقيقية تجريبية عبر واتساب لكافة الفروع.
- [x] اختبار لوحة التحكم وتحديث الأسعار وإخفاء الأصناف والتأكد من انعكاسها المباشر في المنيو.
- [x] خلو قاعدة البيانات من أي أصناف تجريبية أو سجلات معزولة.
- [x] تسليم الدليل الإرشادي الشامل المكتوب للعميل وللمشرفين.

## 4. نطاق الضمان والدعم الفني (Support Scope & Warranty)

### 4.1. الخدمات المشمولة في الضمان المجاني (Included Warranty)
يسري ضمان الصيانة لمدة **[30 يوماً / أو حسب الاتفاق التعاقدي]** من تاريخ توقيع الاستلام، ويشمل:
* إصلاح أي خلل برمجي (Bug) غير متوافق مع المواصفات المذكورة في هذا الدليل.
* مساعدة صاحب المطعم في استعادة الحسابات أو حل مشكلات الاتصال مع Neon أو Vercel.
* معالجة أي توقف في روابط توجيه واتساب نتيجة تحديثات المتصفحات.

### 4.2. الطلبات الخارجة عن نطاق الضمان (Billable Enhancements)
تعتبر البنود التالية تعديلات تطويرية جديدة تخضع لتقدير مالي مستقل:
* إضافة ميزات برمجية جديدة لم تكن ضمن نطاق المشروع (مثل بوابات الدفع الإلكتروني، تتبع السائقين، أو برامج الولاء).
* إعادة تصميم الواجهات البصرية أو إضافة لغات جديدة بخلاف العربية والإنجليزية.
* إدخال مئات الأصناف الجديدة يدوياً بالنيابة عن موظفي المطعم.
